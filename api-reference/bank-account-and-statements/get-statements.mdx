---
title: "Get Statements"
description: "Retrieve cursor-based transaction statements for the selected account."
---

Retrieve statement entries (transaction ledger) and pagination cursor information for the selected account.

```text
POST /v3/statements
```

#### Authentication & Headers

All requests require signed HMAC-SHA256 HTTP headers:

- `Content-Type`: `application/json`
- `X-Client-ID`: Your client identifier.
- `X-Timestamp`: Current UTC epoch timestamp in milliseconds.
- `X-Nonce`: Unique request identifier to prevent replay attacks.
- `X-Signature`: HMAC-SHA256 signature calculated over the canonical header set.
- `X-Content-Hash`: _(Optional)_ Hash of the request body for inbound API calls.

**Targeting the Account:**

- **ACCOUNT Credential:** Bound directly to a specific account. You may omit `X-ISPB` and `X-Account-Number`. If sent, both headers must be present and match the bound account.
- **USER Credential:** Send both `X-ISPB` and `X-Account-Number` to target the account. Include their exact trimmed values in the canonical header set before calculating `X-Signature`.
- **Platform Credentials:** Not accepted on this route.

#### Request

```shellscript
curl --request POST "${BASE_URL}/v3/statements" \
  --header "Content-Type: application/json" \
  --header "X-Client-ID: ${CLIENT_ID}" \
  --header "X-Timestamp: ${TIMESTAMP_MS}" \
  --header "X-Nonce: ${NONCE}" \
  --header "X-Content-Hash: ${CONTENT_HASH}" \
  --header "X-Signature: ${SIGNATURE}" \
  --data '{}'
```

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "statements": [
      {
        "txn_id": "demo-pix-txn-003",
        "amount": "25.00",
        "memo": "Demo supplier payment",
        "created_at": 1767225600000,
        "settlement_id": "demo-settlement-003",
        "payment_method": 1,
        "payment_variant": 1,
        "is_credit": false,

        "txn_type": 1,
        "parent_txn_id": "",
        "parent_settlement_id": "",

        "payee": null
      }

    "cursor": {
      "timestamp": 1767225600000,
      "id": "demo-cursor-001"

```

#### Statement Schema Key Fields

- `amount`: Decimal string representing the entry value.
- `is_credit`: `true` for incoming funds (credit), `false` for outgoing funds (debit).
- `payment_method` / `payment_variant` / `txn_status` / `txn_type`: Integer enum values representing internal transaction lifecycles and types.
- `cursor`: Contains `timestamp` and `id` to pass in subsequent requests for pagination.
