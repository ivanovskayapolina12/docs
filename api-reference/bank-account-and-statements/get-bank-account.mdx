---
title: "Get Bank Account"
description: "Retrieve balances, active PIX keys, limits, webhooks, and fees."
---

Retrieve the balance breakdown, active PIX keys, limits, fee configurations, and registered webhooks for the selected account.

```text
POST /v3/bank_account
```

#### Authentication & Headers

All requests require signed HMAC-SHA256 HTTP headers:

- `Content-Type`: `application/json`
- `X-Client-ID`: Your client identifier.
- `X-Timestamp`: Current UTC epoch timestamp in milliseconds.
- `X-Nonce`: Unique request identifier to prevent replay attacks.
- `X-Signature`: HMAC-SHA256 signature calculated over the canonical header set.
- `X-Content-Hash`: _(Optional)_ Hash of the request body for inbound API calls.

**Targeting the Account:**

- **ACCOUNT Credential:** Bound directly to a specific account. You may omit `X-ISPB` and `X-Account-Number`. If sent, both headers must be present and match the bound account.
- **USER Credential:** Send both `X-ISPB` and `X-Account-Number` to target the account. Include their exact trimmed values in the canonical header set before calculating `X-Signature`.
- **Platform Credentials:** Not accepted on this route.

#### Request

```shellscript
curl --request POST "${BASE_URL}/v3/bank_account" \
  --header "Content-Type: application/json" \
  --header "X-Client-ID: ${CLIENT_ID}" \
  --header "X-Timestamp: ${TIMESTAMP_MS}" \
  --header "X-Nonce: ${NONCE}" \
  --header "X-Content-Hash: ${CONTENT_HASH}" \
  --header "X-Signature: ${SIGNATURE}" \
  --data '{}'
```

#### Success Response (`200 OK`)

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "account_number": "DEMO-TARGET-01",
    "ispb": "00000000",
    "balance": "100.00",
    "frozen_amount": "20.00",
    "available_amount": "80.00",
    "med_frozen_amount": "20.00",
    "other_frozen_amount": "0",
    "currency": "BRL",
    "pix_keys": [
      {
        "pix_key": "demo.receiver@example.test",
        "pix_key_type": 3,
        "status": 1,
        "created_at": 1767225600000
      }
    ],
    "limit_config": null,
    "webhooks": [],
    "fee_configs": []
  },
  "time": 1767225600000
}
```

#### Field Notes & Edge Behaviors

- **Frozen Balances:** `other_frozen_amount` is `frozen_amount - med_frozen_amount`, clamped at zero.
- **Partial Failures:** If balance-snapshot retrieval fails internally, the call still returns `200 OK` with balance components defaulted to `"0"` and `currency: "BRL"`. Failures looking up PIX keys or webhooks return `[]`; limit/fee lookup failures return `null`.
- **Fatal Errors:** Basic account lookup errors remain fatal.
